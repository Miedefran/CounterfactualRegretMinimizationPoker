\paragraph{Abstract}

This paper describes the development of a graphical user interface (GUI) for poker games using PyQt6 as a complement to the bachelor's thesis on Counterfactual Regret Minimization (CFR).
The GUI enables two game modes: Agent vs Human, where players compete against trained AI strategies, and Human vs Human, a multiplayer game over the network.

The implementation demonstrates advanced Python concepts such as PyQt6's Signal-Slot pattern, integration of asyncio with QThread for WebSocket communication, thread-safety mechanisms, comprehensive testing with pytest, and the use of Pickle and compression for serializing trained strategies.

The architecture clearly separates GUI layer, client layer, server layer, and logic layer, enabling reuse of the game logic from the bachelor's thesis.
The work successfully demonstrates how modern Python frameworks and patterns can be used to develop a functional, maintainable, and tested application.
